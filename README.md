# Overview
**ประเภทของ Project:** Web Development, Game Development, IoT (Internet of Things) and Embedded Application

**รายละเอียดและจุดประสงค์ของโปรเจกต์:**
โครงงานนี้คือเกมกระตุ้นการทำงานของสมองที่ถูกออกแบบมาเพื่อพัฒนาทักษะด้านความจำสำหรับทุกเพศทุกวัย โดยเฉพาะกลุ่มผู้สูงอายุที่สามารถใช้เป็นเครื่องมือบริหารสมองเพื่อช่วยชะลอภาวะหลงลืมและฟื้นฟูความจำได้อย่างมีประสิทธิภาพ จุดเด่นที่สร้างความน่าสนใจคือการบูรณาการระบบกระดานคะแนน (Scoreboard) เข้ามาใช้เป็นเครื่องมือติดตามพัฒนาการอย่างเป็นรูปธรรม ซึ่งนอกจากจะช่วยให้ผู้เล่นหรือผู้ดูแลสามารถประเมินความก้าวหน้าทางความจำได้อย่างต่อเนื่องแล้ว ยังเป็นการเพิ่มแรงจูงใจให้การฝึกสมองกลายเป็นกิจกรรมที่สนุกและท้าทายมากยิ่งขึ้น

**Hardware ที่ใช้:**
- Arduino UNO R4 WiFi
- จอ LCD
- หลอดไฟ LED 4 สี
- ปุ่มกด 4 ปุ่ม
- Breadboard
- Resistor 4 ตัว

**Libraries ที่ใช้:**
- `WiFiS3.h`
- `Wire.h`
- `LiquidCrystal_I2C.h`

**Tools เพิ่มเติม:**
- Vite
- Tailwind CSS
- Node.js และ npm
- Git 
- Google Sheets (ใช้สำหรับทำฐานข้อมูล Score board)

# Overview
**ประเภทของ Project:** Web Development, Game Development, IoT (Internet of Things) and Embedded Application

**รายละเอียดและจุดประสงค์ของโปรเจกต์:**
โครงงานนี้มุ่งเน้นประโยชน์เกี่ยวกับการฝึกความจำ ประโยชน์ที่ได้จากการเล่นคือผู้เล่นได้ฝึกทักษะด้านความจำ ซึ่งสามารถช่วยฝึกความจำสำหรับผู้สูงอายุได้ด้วย 

**ความแปลกใหม่และความน่าสนใจ:**
มีการเก็บคะแนนในรูปแบบของ Score board เพื่อเป็นการเช็คและติดตามการพัฒนาด้านความจำของผู้เล่น

**Hardware**
- Arduino UNO R4 WiFi
- จอ LCD
- หลอดไฟ LED 4 สี
- ปุ่มกด 4 ปุ่ม
- Breadboard
- Resistor 4 ตัว
- Case (กล่อง)

**Libraries ที่ใช้:**
- `WiFiS3.h`
- `Wire.h`
- `LiquidCrystal_I2C.h`

**Tools เพิ่มเติม:**
- Vite
- Tailwind CSS
- Node.js และ npm
- Git 
- Google Sheets (ใช้สำหรับทำฐานข้อมูล Score board)
